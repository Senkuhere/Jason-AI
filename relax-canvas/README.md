# Soothing Orb Garden

A lightweight, high-performance interactive 2D Canvas web game designed with a cinematic dark theme and your preferred minimal cyan glow.

## Features
- **No Heavy Libraries:** Built with pure HTML5 Canvas 2D and vanilla JavaScript for instant loading and silky smooth 60fps performance on both mobile and desktop.
- **Cinematic Visuals:** Dark aesthetic with slow ambient cyan pulsing glows on the upper, right, and bottom borders.
- **Engaging Gameplay:** Tap or click glowing orbs to collect energy and trigger particle bursts and ripples. Tap empty space to gently bloom new orbs.
- **Fully Responsive:** Adapts seamlessly to any screen resolution, including 1080x2460 mobile displays.

## How to Run
1. Open your terminal or server in the project root directory.
2. Serve via a local web server (e.g., Python: `python -m http.server 8000`).
3. Open `http://localhost:8000/relax-canvas/index.html` in your browser.
