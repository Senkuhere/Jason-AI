# Quantum Clash - Modern Rock Paper Scissors

A high-tech, modern realistic Rock Paper Scissors web application featuring atmospheric dark UI, glowing particle orbs, smooth animations, sound-less haptic feedback visual cues, win-streak tracking, and keyboard support.

## Project Structure

- **`index.html`**: The main interface structure containing the header scoreboards, battle stage arena, weapon selection deck, and rules modal.
- **`css/style.css`**: Realistic dark-fantasy & futuristic styling with backdrop blur glassmorphism, floating ambient glow orbs, interactive button transitions, and badge alert states.
- **`js/game.js`**: Core game logic handling randomized AI opponent choices, win/loss/tie adjudication, animated card shakes & reveals, stats (win rate and streak count), and keyboard shortcuts (`1`, `2`, `3`).

## How to Play

1. Open `rock-paper-scissors-game/index.html` in any web browser.
2. Click on **Rock**, **Paper**, or **Scissors** (or press keys **1**, **2**, **3** on your keyboard).
3. Watch the quantum clash animation reveal the winner!
4. Track your live win rate, streak, and match history.
