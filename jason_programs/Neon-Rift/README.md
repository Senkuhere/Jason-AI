Neon Rift
=========

A top-down neon arena roguelite prototype built with Python and Pygame.

Run:

1. Create a virtual environment (recommended):
   python -m venv venv
   source venv/bin/activate  # mac/linux
   venv\Scripts\activate     # Windows

2. Install pygame:
   python -m pip install pygame

3. Run the game:
   python main.py

Notes:
- This repository uses programmatic graphics only (no external assets).
- The project is organized into modules: game, player, enemies, projectile, particle, wave_manager, ui, save_manager.
- This is an iterative prototype (Stage 1+2). I'll continue implementing further stages on request, Sir.
